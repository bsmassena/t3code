# Appearance

Open **Settings → Appearance** to change how T3 Code presents the interface.

## Syntax highlighting

Use **Syntax highlighting** to choose the colors used for code tokens in chat code blocks, diffs,
file previews, and project search results. **T3 Code** keeps the default palette. **VS Code** uses
the matching VS Code Light+ or Dark+ palette for the current appearance.

This preference is stored on the current web or desktop client.

## Composer context

Git-backed projects show branch and worktree controls below the composer while you create a thread.
The controls retreat as the composer docks after you send the first message.

Turn on **Composer context** to keep those controls visible after the thread starts. This preference
applies to the web and desktop clients.
